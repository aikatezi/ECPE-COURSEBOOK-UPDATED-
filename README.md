# ECPE Coursebook — Clean New Repository

This is a **fresh standalone website** with regular HTML links instead of the previous overlay/iframe navigation.

## Upload

1. Create a **new public GitHub repository**.
2. Upload **all files and folders at the top level**, preserving the exact `assets/` structure. Because GitHub's web uploader can reject large batches, upload in smaller groups or use GitHub Desktop (recommended).
3. In Settings > Pages choose **Deploy from a branch**, `main`, `/ (root)`.
4. Check the published URL. All links are relative, so the same files work under any repository name.

## Pages

- `index.html`: Netflix-style series selection.
- `grammar.html`: three authentic Grammar episode cards.
- `present-lab.html`, `future-lab.html`, `past-lab.html`: **isolated** Legally Blonde-style grammar lessons.
- `vocabulary.html`: Reading & Vocabulary episodes.
- `reading-human-nature.html` and `reading-sports.html`: material transferred from the existing coursebook.
- `writing.html` and `writing-essay.html`: Writing episode and model material.
- `speaking.html` and `speaking-survival-guide.html`: Speaking guide.
- `audio-test.html`: 7 original MP3 players to verify audio playback.

**Important:** Reading and Writing contain older original lesson material and may still need browser-level functional checks. A successful build validates file paths and markup, not every existing interaction. Test these pages before sharing the new site with students.

The old GitHub repository and Cloudflare site are not changed by this ZIP.
